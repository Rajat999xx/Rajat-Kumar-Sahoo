================================================================================
8. INTERACTION & STATE LOGIC
================================================================================

1. Hotspot Pin Interaction:
   - Clicking a '+' hotspot opens the Quick View modal for that specific product.
   - On Desktop: The modal appears anchored near the hotspot or in an adjacent flyout with smooth fade/scale transition (opacity: 0 -> 1, transform: scale(0.95) -> scale(1)).
   - On Mobile: The modal opens as a centered or bottom sheet popup with a dark backdrop (rgba(0, 0, 0, 0.5)).

2. Close Modal Interaction:
   - Clicking the "X" button (top-right) closes the modal.
   - Clicking outside the modal container (on the backdrop overlay) closes the modal.
   - Pressing the Escape key on keyboard closes the modal.

3. Color Swatch Switching:
   - Clicking an unselected color swatch toggles it to active (black pill background, white text).
   - Updates the internal selected variant ID.
   - Updates the thumbnail image, price, and availability based on the chosen color + currently selected size.

4. Size Dropdown Interaction:
   - Clicking the size box toggles the custom dropdown menu open/closed (rotate(180deg) on chevron).
   - Clicking a size option selects it, closes the menu, and updates the displayed size text.
   - Clicking outside the dropdown closes the dropdown menu.
   - Re-evaluates variant availability and price for the chosen size + color combination.

5. Add to Cart AJAX Submission:
   - Submits POST /cart/add.js with the selected variant ID and quantity 1 via fetch.
   - On success: Dispatches Shopify theme cart event / opens Dawn's cart drawer (cart-drawer or custom notification) and shows a brief success state ("ADDED!").
   - On error: Displays the error message inside the modal (e.g. "Sold out" or inventory limitation).
